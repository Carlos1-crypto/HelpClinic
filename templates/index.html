Recursos Principais

🔐

Segurança Enterprise

Senhas criptografadas com bcrypt e autenticação JWT. Seus dados estão protegidos com os melhores padrões de segurança.

📅

Agendamento Inteligente

Sistema de marcação de consultas com calendário brasileiro integrado, validações automáticas e notificações.

👥

Gestão de Pacientes

Cadastro completo com histórico de consultas, informações de contato e histórico médico organizado.

📊

Relatórios Avançados

Análises de desempenho, estatísticas de consultas e insights sobre sua clínica em tempo real.

🌐

API REST Profissional

Backend desenvolvido em Flask com CORS, suportando múltiplas plataformas e integrações externas.

⚡

Frontend Ultra Moderno

Interface construída com Next.js, React e TypeScript. Experiência de usuário otimizada e responsiva.

Endpoints da API

POST
/api/auth/login
Autenticar usuário e obter token JWT
POST
/api/auth/register
Registrar novo usuário no sistema
POST
/api/auth/logout
Encerrar sessão e limpar token
GET
/api/auth/me
Obter dados do usuário autenticado
# Exemplo de login curl -X POST http://localhost:5000/api/auth/login \   -H "Content-Type: application/json" \   -d '{     "email": "usuario@example.com",     "senha": "Pass123"   }'
